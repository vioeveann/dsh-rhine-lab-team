# 发布与安装

## 包内容

```
index.js            Host 半区加载器
host/*.js           路由、工具、设置、模板、记忆
client.js           Client 半区（单个 classic 脚本）
templates/          团队模板（研究组 / 写作组）
docs/               设计说明、运行时笔记、本文件
locale/             详情页文案
LICENSE             MIT
```

自带成员（审计员 / 资料整理 / 写作）由 `host/builtin-bots.js` 在首次启动时种下，不随包附带 `bots/`；个人成员、测试 Bot、记忆和头像都不进包。

## 发布前检查

先确认 npm 上 `dsh-avatar-frame` 的 `latest` 已经是 `0.15.0` 或更高：本插件把依赖声明为 `latest`，安装/更新时会拉最新版；如果 npm 上还没有 0.15.0，装到的会是旧版，子会话头像与 ID 不完整。发布顺序是先发头像插件，再发本插件。

```sh
git status                       # 应该干净，没有漏提交的改动
node --test test/*.test.mjs      # 全部测试
node --check client.js index.js  # 语法
node --check host/*.js
npm pack --dry-run               # 看会打进去哪些文件
```

## 安装

```sh
dsh plugin add <包名或本地路径>
```

装好后：

1. 在插件列表里**启用 dsh-team**（bundle 需要单独启用一次）；
2. 可选：同时启用 `dsh-avatar-frame` ≥ 0.15，子会话才会显示 Bot 自己的头像和名字；
3. 新开会话，在**新会话页**或输入框下方打开「团队协作」开关；
4. 右侧栏出现「成员」面板，点 `＋` 建第一个 Bot，或点「套用模板」用现成的一套。
